# Jalons 26 à 28 — sécurité, caution et volumes

## Jalon 26 : sécurité et confidentialité

Tous les nouveaux téléphones passent par
`modules/accounts/phones.py`. Le format conservé est E.164, par exemple
`+2250700000000`. Les variantes commençant par `00` sont converties, mais un
numéro national ambigu est refusé.

Les routes d'inscription, connexion et OTP utilisent des limites par IP et par
numéro. Les OTP de documents ont aussi un délai de refroidissement : une
demande répétée pendant cette fenêtre réutilise le même challenge et ne place
pas un deuxième message dans la file.

La vérification publique d'une référence renvoie uniquement le type, le statut,
le montant, la période et la date d'émission. Les noms, téléphones, moyen de
paiement et adresse restent réservés au parcours sécurisé avec OTP.

## Jalon 27 : clôturer une caution

L'écran Paiements charge `GET /api/v1/security-deposits/`. Pour une caution
encore détenue, le bailleur choisit :

1. remboursement ;
2. retenue avec motif ;
3. affectation à un loyer du même bail avec preuve d'accord.

`POST /api/v1/security-deposits/{id}/settle/` verrouille les obligations,
contrôle le solde, enregistre le mouvement et génère un relevé PDF. Aucune de
ces étapes ne déplace de fonds via ImmoLib.

## Jalon 28 : éviter les gros chargements

Le tableau de bord appelle maintenant
`GET /api/v1/dashboard/overview/`. Django calcule les indicateurs, les cinq
échéances prioritaires, les cinq derniers paiements et six agrégats mensuels.
Le navigateur ne télécharge donc plus tout l'historique pour faire ces calculs.

Les listes importantes acceptent `?page=1&page_size=25`, avec un maximum de
100 éléments. Des index couvrent les recherches fréquentes sur les statuts,
dates, types d'obligation et baux. Les filtres de dates disponibles sont :

- échéances : `period`, `period_from`, `period_to` au format `AAAA-MM` ;
- paiements : `received_from`, `received_to` au format `AAAA-MM-JJ` ;
- documents : `issued_from`, `issued_to`, `document_type`, `status`.

Le frontend affiche une navigation Précédent/Suivant pour les paiements et les
documents. Recharts reçoit seulement les six lignes agrégées du tableau de
bord.
